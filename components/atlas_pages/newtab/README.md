# Atlas new tab page

The page Atlas shows in a new tab: the badge, the name, a search field, the pinned pages and the pages to pick up. It is a self-contained internal page (HTML, CSS and a small script, no network, no framework, the WolOS theme variables only), like the first-run page. Spec: `brand/atlas/chrome/tokens.md` section 5 and `motion.md` ("New tab page appears"); reel scene R02b.

| Part | What |
|---|---|
| Badge, "Atlas" | the badge at 72 px, the name 26 px bold |
| Search field | 560 x 40, radius 10. Enter hands the text to the host (an address opens, anything else is a search with the default provider, no suggestions). `/` jumps to it, Escape clears it |
| Pinned | up to 12 cards 96 x 88 (6 in a row at 656 px); a 32 px tile in the category colour; Delete or the small button on the card takes it off |
| Pick up where you left off | up to 4 cards 320 x 64: title and "Opened 20 minutes ago". With none: the empty state (icon, title, hint, one action) |
| Status line | "Do Not Track is on", 24 px, only while the setting is on and no window strip shows it |
| Entrance | the four blocks rise 8 px and fade in 30 ms apart (250 ms each), only the first time a window shows the page; reduced motion jumps |

## Files

| File | What |
|---|---|
| `index.html` | the page; the badge and the glyphs as an inline sprite; a CSP meta (`default-src 'none'`, scripts and styles from the page, Trusted Types) |
| `newtab.css`, `newtab.js` | layout, motion, states (variables only); logic (no markup written from text) |
| `host.js` | the preview host (sample pages, chosen with `?state=filled|empty|nopins|long&strip=1&dnt=0&enter=0`) |
| `host.engine.js` | the engine's adapter, served under the name `host.js` inside Atlas |
| `theme.css`, `categories.css` | preview tokens, generated by `tools/gen_theme.py` (the engine serves the live theme and the category colours under these names) |
| `newtab_categories.*`, `newtab_state.*` | C++ without a //chrome dependency: host category table, the pinned list, the state sent to the page |
| `newtab_resources.grd`, `BUILD.gn` | the page as resources |
| `tools/check.py` | static checks: structure, no network, no colour literals, type sizes, no upstream name, contrast |
| `tools/capture.mjs` | headless run: DOM check of R02b, stagger, keyboard, captures, narrow, reduced motion, adapter |
| `tools/gen_theme.py`, `tools/mark.py`, `tools/sprite.py`, `tools/mkpatch.py` | theme and sprite generators; the generator of patch 0051 |
| `testdata/` | a state as the handler sends it |

The handler, the UI controller and the config are in `chrome/browser/ui/atlas/newtab/` (a handler here would make a dependency cycle: `//chrome/browser` depends on `//components/atlas_pages`).

## The host contract (`window.atlasNewTab`)

```
getState()          -> Promise<{ pinned: [{title, url, category}],       category: web|talk|files|media|store|system
                                 recent: [{title, url, when}],           when: ms since 1970
                                 doNotTrack: bool,
                                 statusStrip: bool,                      the window shows its own strip: hide the page's line
                                 firstInWindow: bool,                    play the entrance
                                 reducedMotion: bool | null,
                                 strings: { key: text } }>               optional; {0} marks a value
open(url, {newTab}) -> void        web addresses only
submit(text)        -> void        the host decides between an address and a search
pin(url, title)     -> Promise<void>
unpin(url)          -> Promise<void>
```

Messages on the engine side: `getState(id)`, `open(url, newTab)`, `submit(text)`, `pin(id, url, title)`, `unpin(id, url)`; an answer runs `atlasNewTabHost.resolve(id, value)` in the page.

## Check

```
python3 -I tools/check.py
python3 -I tools/gen_theme.py <wolos-src> --check
python3 -I -m http.server 8472 --bind 127.0.0.1 &     # stop it afterwards
PLAYWRIGHT_CORE=<playwright-core dir> CHROME=<browser binary> node tools/capture.mjs http://127.0.0.1:8472/index.html preview <reel>/out/poses/atlas-ntp-light.png
```

Serve it over http: under `file://` the CSP's `'self'` does not cover the scripts.

## How the patch series wires it

`atlas/patches/ui/0050-newtab-url.patch` registers `atlas::newtab::NewTabUIConfig` in place of the engine's config for the host `new-tab-page` (the engine's new tab address; incognito and guest keep their own page). `0051-newtab-handler.patch` is generated by `tools/mkpatch.py` from the files here and in `chrome/browser/ui/atlas/newtab/`; `0052-newtab-strings.patch` fills `chrome/app/atlas/pages_strings.grdp`.
